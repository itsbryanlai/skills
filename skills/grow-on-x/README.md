# grow-on-x

**Status: Beta** — distilled from one practitioner's 2026 playbook and still being tested against real accounts; the steps and numbers may change.

Coach follower growth on X (Twitter): audit the profile, plan and draft posts in formats that work,
draft replies to bigger accounts, set a daily post-and-reply routine sized to the account, and read
analytics to decide what to change. Reply-first and proof-led, with honest timelines.

Based on Graham Mann's
[How to Grow Your Followers on X (Twitter): What's Actually Working in 2026](https://grahammann.net/blog/how-to-grow-on-x-twitter-2026).

Verified on: not yet evaluated on any tool.

See [SKILL.md](SKILL.md) for the full instructions — it's tool-neutral and can be pasted into any
chat model or agent.
